Árfolyamok és devizakereskedés
egy helyen

Böngésző alapú asztali alkalmazás Java Spring Boot keretrendszerrel

Az alkalmazás a Magyar Nemzeti Bank SOAP webszolgáltatásából kérdezi le a hivatalos devizaárfolyamokat és grafikonon ábrázolja őket, valamint az Oanda API segítségével egy teljes Forex kereskedő klienst valósít meg: számlainformációk, aktuális és historikus árak, pozíciók nyitása, listázása és zárása.

  • MNB árfolyamok
  • Forex kliens

Mit tud az alkalmazás?

MNB SOAP kliens

Devizaárfolyamok lekérdezése tetszőleges időszakra a Magyar Nemzeti Bank webszolgáltatásából.

Grafikonok

A lekérdezett árfolyamok táblázatban és Chart.js grafikonon is megjelennek.

Forex kereskedés

Oanda demo számla kezelése: aktuális és historikus árak, pozíciók nyitása és zárása piaci áron.

Java 25 + Spring Boot

Egyetlen futtatható JAR fájl: java -jar beadando.jar, majd böngészőben localhost:8080.

Menüpontok

SOAP – MNB

Deviza és időszak kiválasztása, az árfolyamok kiírása és grafikonon való ábrázolása.

  • Megnyitás

Forex-account

  • Megnyitás

Forex-AktÁr

Egy kiválasztott instrumentum (pl. EUR_USD) aktuális vételi és eladási ára.

Forex-HistÁr

  • Megnyitás

  • Megnyitás
